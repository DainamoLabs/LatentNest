LatentNest Privacy Policy

Effective October 15, 2026

LatentNest does not collect, sell or share your data. Everything it saves stays in your browser. Data only leaves your device when LatentNest downloads an image you chose to add, and when it sends images to the captioning server that you set up yourself.

What LatentNest stores

Everything below is stored only in your browser profile, in the extension's own storage. It is not synced to any account or sent to Dainamo Labs.

  • The images you add, with the address of each image and of the page it came from.
  • Your datasets, captions, crops, captioning hints and review state.
  • Your settings: the captioning server's address, the model name, your caption styles, and an API key if you enter one.

What leaves your device

  • Image downloads. When you add an image, LatentNest downloads it from the website that hosts it. This is the same request your browser makes to display the image, including that site's cookies, so images behind a login can be saved.
  • Captioning. When you generate captions, LatentNest sends the image, the caption instructions and any captioning hint to the server address you entered in Settings, along with your API key if you set one. By default this is a server on your own computer (localhost). If you point LatentNest at a server on another machine or at a third-party service, that service receives those images, and its own privacy policy applies.

Nothing else is sent anywhere. LatentNest has no analytics, telemetry, ads, crash reporting or accounts, and it does not load code from the internet.

Access to websites

Access to all websites is optional, and LatentNest asks for it from its side panel. With it, a small script in each page notes where you last right-clicked and where the pointer is. These positions stay in that page and are used only to find the picture under the cursor when you choose Add to Dataset or press the keyboard shortcut. The script does not read page text, forms or your browsing history.

Some sites block reading the pixels of a video. When you add a frame from such a video, LatentNest takes a screenshot of the visible tab, keeps only the part covered by the video, and discards the rest.

Backups and exports

Backups and dataset exports are files saved to your computer when you ask for them. Backups never include your API key.

Deleting your data

Delete images or datasets from the side panel at any time. Uninstalling LatentNest, or clearing your browser's data for the extension, removes everything it stored.

Changes to this policy

Any change will be posted on this page with a new effective date. Earlier versions are kept in the project's history on GitHub.

Contact
